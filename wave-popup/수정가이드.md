# 직접 수정하는 방법

소스 주석은 `[구조 설명]`, `[직접 수정]`, `[확장 위치]`로 구분했습니다. 편집기의 검색 기능으로 찾을 수 있습니다.

## 자주 바꾸는 항목

| 변경할 항목 | 파일 및 검색어 | 바꾸는 값 |
|---|---|---|
| 상하단 배경색 | css/popup.css → :root | --navy |
| 회색 패널 색 | css/popup.css → :root | --panel |
| PC 상하단 높이 | css/popup.css → :root | --bar-height |
| 패널 가장자리 여백 | css/popup.css → :root | --edge |
| 패널 둥근 정도 | css/popup.css → :root | --radius |
| 로고 크기 | css/popup.css → .brand-logo | width, height, font-size |
| 프로젝트명 크기 | css/popup.css → .brand-name | font-size |
| WAVE 크기·간격 | css/popup.css → .page-title | font-size, letter-spacing |
| 미니맵 크기·위치 | css/popup.css → .minimap | width, height, left, top |
| 오른쪽 패널 너비 | css/popup.css → .right-panel | width |
| 버튼 사이 간격 | css/popup.css → .controls | gap |
| 장바구니 높이 | css/popup.css → .cart | min-height |
| 버튼 표시 문구 | js/popup.js → renderControls | 3인칭, 1인칭, 소리 ON/OFF 문자열 |
| 장바구니 제목 | index.html → cartTitle | SHOPPING CART |

모바일 화면에서는 CSS 아래쪽 `@media` 규칙이 덮어씁니다. PC 값을 수정해도 모바일에 반영되지 않으면 같은 선택자를 미디어 쿼리에서 찾아 수정하세요.

## JSON 설정 설명

표준 JSON은 주석을 허용하지 않습니다. `data/project.json`에 // 또는 /* */를 넣지 마세요. 설명은 이 문서에서 확인합니다.

| 키 | 의미 | 예시·허용값 |
|---|---|---|
| projectName | 프로젝트명과 브라우저 제목에 사용 | "이재범이 직접 구현한 ..." |
| logo | 로고 이모지 문자열 | "🥲" |
| pageTitle | 상단 중앙과 브라우저 제목에 사용 | "WAVE" |
| initialView | 초기 시점 설정 | "third-person" 또는 "first-person" |
| soundEnabled | 초기 소리 설정 | true 또는 false — 따옴표 없이 사용 |

JSON과 JS는 빌드에 포함됩니다. 수정 후 `npm run build`를 실행하고 새로고침하세요. 처음에는 `npm install`이 필요합니다. HTML/CSS는 빌드 없이 반영됩니다.

## 맵과 카메라 설정 — data/scene.json

JSON에는 주석을 넣을 수 없으므로 아래 설명을 참고하세요.

| 키 | 의미 |
|---|---|
| spawn | 시작 위치 [x, z]. 바닥이 있는 좌표를 사용합니다. |
| thirdPersonDistance | 3인칭 기본 거리. 기본 32. 휠 줌은 없습니다. |
| thirdPersonElevation | 3인칭 기본 내려다보는 각도(라디안). 기본 0.72 |
| eyeHeight | 1인칭 눈높이. 기본 1.65 |
| walkSpeed / runSpeed | 걷기 / Shift 달리기 초당 속도 |
| stepHeight | 자동으로 올라갈 수 있는 단차 높이 |
| maxDrop | 한 번에 내려갈 수 있는 최대 단차 |

맵은 최대 가로/세로 폭 70으로 정규화하고 중앙을 x/z 원점, 최저점을 y=0으로 맞췄습니다. 원본 FBX는 assets/models에 보관하며 실행 때는 data/map.json 형상을 사용합니다. FBX를 교체하려면 형상을 다시 변환해야 합니다.

## 코드별 수정 위치

- js/scene.js: 맵 재질 색, 조명, 임시 캐릭터, 바닥·벽 판정, 카메라, 미니맵.
- js/camera-controls.js: 드래그 감도와 시선 방향 계산.
- js/movement-input.js: 키보드 매핑. 한글 입력 상태에서도 물리 키 위치로 동작합니다.
- js/popup.js: 버튼 상태와 이벤트. popup:view-change는 실제 카메라에 연결되어 있습니다.
- css/popup.css: .popup/.scene의 overflow와 영역 크기가 맵을 중앙 안에 제한합니다.
- index.html: UI 구조와 하단 조작 안내. id를 변경하면 JS 참조도 맞춰 주세요.

벽과 바닥은 레이캐스트로 검사합니다. 점프나 중력 시뮬레이션은 없으며 지나치게 큰 단차와 맵 밖으로 이동하지 못하도록 막습니다. 카메라가 벽에 가려질 때만 자동으로 거리를 줄입니다.

소리 버튼은 아직 실제 음원을 재생하지 않습니다. 장바구니는 빈 UI이며 서버도 없습니다.

## 수정 후 확인

JS/JSON 수정 후 빌드 → 브라우저 새로고침 → 시점 전환, 이동, 드래그를 확인하세요. js/app.bundle.js는 자동 생성물이므로 수정하지 마세요.
